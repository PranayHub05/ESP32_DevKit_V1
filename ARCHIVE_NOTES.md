# Archive Notes

This archive is a consolidated project record, not a byte-for-byte backup of every historical Arduino IDE sketch.

The available project history reliably identifies:
- the classic ESP32 DevKit V1/WROOM-32 platform;
- the Wi-Fi car work and its documented pin configurations;
- the DHT11/MQ135/WebSocket/JSON architecture;
- the OpenWeather + sensor integration architecture;
- successful Bluetooth Classic A2DP testing;
- DevKit V1 use as a USB-UART bridge for ESP32-CAM;
- and the proposed, but unfinished, I²S-to-A2DP bridge.

Where an exact historical GPIO assignment or exact old source listing was not available, the individual sketch uses clearly marked configurable constants rather than inventing that value.

This distinction is intentional: the archive is meant to be useful without falsely claiming that reconstructed code is the exact historical source.
